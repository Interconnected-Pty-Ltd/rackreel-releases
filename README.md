# RackReel releases

AI-powered cue sports video editing.

This is the public distribution repository for RackReel installers and the
matching third-party source, licence notices and build materials. RackReel's
proprietary application source is maintained separately in a private repository.

Download [RackReel 0.4.0](https://github.com/Interconnected-Pty-Ltd/rackreel-releases/releases/tag/v0.4.0)
from Releases. Matching third-party source, licence notices, build/replacement
instructions and SHA-256 checksums accompany the installers.

- Mac: Apple Silicon, macOS 15 or newer; Developer ID signed and Apple notarized.
- Windows: x64, Windows 10 or newer. **The Windows installer is unsigned** while
  publisher signing is being configured. Windows may show an unknown-publisher
  or reputation warning. Check its SHA-256 checksum before installation.

Only the artifacts listed in a published release are public distributions;
development, staging and private trainer builds are not included.

- Product and account: https://rackreel.app
- Support: support@interconnected.au

Release assets will identify their version, supported operating systems,
architecture, SHA-256 checksums and platform signing status. Third-party source
materials retain their original copyright and licence terms.
